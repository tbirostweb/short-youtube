# Outils YouTube Shorts

Deux projets autour de la création de vidéos courtes :

- `shorts-factory/` : chaîne de production automatisée, du sujet au montage et à la publication.
- `ytshorter/` : application qui repère et découpe des extraits de vidéos en clips verticaux sous-titrés.

Consultez les README des sous-projets pour les prérequis et la configuration. Les identifiants, bases locales, vidéos, pistes audio et caches sont exclus du dépôt. La police Anton incluse est sous licence OFL (voir `shorts-factory/data/assets/fonts/OFL.txt`).

Projet présenté par [BirostWeb](https://birostweb.fr).
